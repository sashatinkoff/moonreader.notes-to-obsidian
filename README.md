# MoonReader Importer

Плагин превращает экспорт заметок из **Moon+ Reader** в аккуратные заметки Obsidian: одна цитата — один файл, плюс карточка книги. Работает без Python и сторонних плагинов, в том числе на мобильном Obsidian.

## Установка

1. Положите папку `moonreader-importer` (файлы `main.js`, `manifest.json`, `README.md`) в `<хранилище>/.obsidian/plugins/`.
2. Перезапустите Obsidian и включите плагин в **Настройки → Сторонние плагины**.

## Использование

1. Выполните команду **«Импортировать заметки MoonReader»** (палитра команд) или нажмите значок книги на боковой панели.
2. Выберите файл экспорта Moon+ Reader.
3. Введите имя автора — оно запишется во все заметки.
4. При необходимости укажите **время чтения**. Можно ввести десятичные часы (`2,34` = 2 часа 20 минут; `5,75` = 5 часов 45 минут) или формат часы:минуты (`2:00`). При импорте значение округляется до минуты и сохраняется как `Ч:ММ`.
5. Нажмите **«Импортировать»**.

## Что создаётся

```
<Папка карточек>/
  Название книги.md              ← карточка книги
<Папка заметок>/
  Название книги.notes/
    123 Первые пять слов.md      ← заметка-цитата
```

Имя заметки: ID из Moon+ Reader и первые пять слов цитаты (или комментария, если цитаты нет).

## Атрибуты заметки

Каждая заметка получает свойства (YAML-шапку):

| Свойство | Значение |
|---|---|
| `Автор` | автор, введённый при импорте |
| `Дата` | дата импорта заметки в формате `ГГГГ-ММ-ДД` |
| `Источник` | список со ссылкой на карточку книги |
| `Предыдущая заметка` | ссылка на предыдущую заметку **этой же книги** |
| `Следующая заметка` | ссылка на следующую заметку **этой же книги** |

Пример шапки:

```yaml
---
Автор: Иван Иванов
Дата: 2026-11-12
Источник:
  - "[[Название книги]]"
Предыдущая заметка: "[[101 Первые слова предыдущей]]"
Следующая заметка: "[[103 Первые слова следующей]]"
---
```

Важно:

- Порядок заметок — тот, в котором они идут в файле экспорта.
- У **первой** заметки книги нет `Предыдущая заметка`, у **последней** — нет `Следующая заметка`. Свойство в этом случае просто не добавляется.
- Ссылки на книгу и соседние заметки записаны в кавычках (`"[[...]]"`), поэтому Obsidian распознаёт их как ссылки в свойствах. Дата заметки записывается в ISO-формате `ГГГГ-ММ-ДД`.
- Соседи ищутся только внутри одной книги: заметки разных книг друг с другом не связываются.

Ниже в заметке идёт цитата в блоке `> [!quote]`, а под ней ваш комментарий (если он был).

## Карточка книги

Карточка книги содержит только следующие свойства:

```yaml
Автор: Иван Иванов
Название: Название книги
Дата прочтения: 12.11.2026
Оценка:
Жанр:
  -
Заметки: "[[123 Первые слова цитаты]]"
tags:
  -
Время чтения:
```

`Автор`, `Название` и `Дата прочтения` заполняются при импорте. `Заметки` ссылается на **первую** заметку книги. `Оценка`, `Жанр`, элемент списка `tags` и `Время чтения` остаются пустыми, если время не указано в окне импорта.

## Как определяется название книги

Moon+ Reader иногда пишет вместо названия имя файла (`book_123456.epub`). Плагин группирует заметки по пути к файлу книги и берёт одно название на все заметки: самое частое «человеческое». Если его нет — делает читаемое название из имени файла.

## Настройки

- **Папка карточек книг** — по умолчанию `Прочитанные книги`. Поле подсказывает существующие папки хранилища; можно и ввести новый путь, он будет создан при импорте.
- **Папка заметок** — тоже с подсказкой существующих папок. По умолчанию `Прочитанные книги`. Если ваш каталог читает папку рекурсивно и цитаты в нём не нужны, укажите отдельную папку.

## Предупреждения

- Повторный импорт той же книги **перезаписывает** файлы с теми же именами, включая карточку: введённые вручную значения `Оценка` и `Жанр` будут потеряны.
- Из имён убираются символы `# ^ [ ] \ / : * ? " < > |`, чтобы не ломать ссылки.
